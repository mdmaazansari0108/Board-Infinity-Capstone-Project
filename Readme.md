\# Board Infinity Capstone Project: Digital Marketing \& Growth Strategy



\## Executive Summary

Comprehensive 10-week growth marketing capstone project for Board Infinity, targeting non-tech graduates ("Aarav" persona) for data analytics and tech bootcamps.



\## Project Deliverables \& Phases

\- \*\*Phase 1: Technical Audit \& SEO Remediation\*\*

&#x20; - Screaming Frog audit covering 500 URLs.

&#x20; - PageSpeed Insights optimization (LCP \& mobile load fix).

&#x20; - Remediation of 404 broken links and metadata issues.

\- \*\*Phase 2: Content Funnel Deployment \& Paid Media\*\*

&#x20; - 3-tier content architecture (ToFu, MoFu, BoFu).

&#x20; - Paid media budget model (₹1,00,000 spend split across Google, Meta, and LinkedIn).

\- \*\*Phase 3: GA4 Tracking \& Executive Dashboards\*\*

&#x20; - Google Analytics 4 custom event specification schema.

&#x20; - Interactive Looker Studio Executive Dashboard.



\## Key Performance Indicators \& Financial ROAS

\- \*\*Total Users Reached:\*\* 125,300

\- \*\*Conversion Rate:\*\* 7.02%

\- \*\*Blended CPL:\*\* ₹500.00 / ₹565.00

\- \*\*Gross Revenue Generated:\*\* ₹3,45,150

\- \*\*Gross ROAS:\*\* 3.45x

\- \*\*Net Profit:\*\* ₹2,45,150
