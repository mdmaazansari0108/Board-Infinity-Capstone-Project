Board Infinity Capstone Project: Digital Marketing \& Growth Strategy



Executive Summary



Comprehensive 10-week growth marketing capstone project for Board Infinity, targeting non-tech graduates ("Aarav" persona) for data analytics and tech bootcamps.



Total Spend: ₹7,000 (₹1,000/day CBO)



Total Revenue: ₹16,182 (18 Purchases @ ₹899 AOV)



Blended ROAS: 2.31x (Peaking at 3.85x in BOF retargeting)



Blended CPA: ₹389 (19% below the ₹480 break-even target)



Project Deliverables \& Phases



Phase 1: Technical Audit \& SEO Remediation



Screaming Frog audit covering 500 URLs.



PageSpeed Insights optimization (LCP \& mobile load fix).



Remediation of 404 broken links and metadata issues.



Phase 2: Content Funnel Deployment \& Paid Media



3-tier content architecture (ToFu, MoFu, BoFu).



Paid media budget model (₹1,00,000 spend split across Google, Meta, and LinkedIn).



Phase 3: GA4 Tracking \& Executive Dashboards



Google Analytics 4 custom event specification schema.



Interactive Looker Studio Executive Dashboard.
